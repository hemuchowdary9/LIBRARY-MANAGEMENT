# Project Statement

## Project Title

Library Management System

## Problem Statement

Managing books and members manually in a library can take more
time and can lead to mistakes in maintaining records.

The Library Management System provides a simple Python-based
solution for managing basic library operations.

## Proposed Solution

The proposed system allows the user to:

- Add books
- View available books
- Register library members
- View member details
- Issue books
- Return books
- Search for books
- Generate a library report
- Store book and member information

## Functional Requirements

1. The system should allow the user to add books.
2. The system should display the list of books.
3. The system should allow new members to be registered.
4. The system should display member details.
5. The system should allow books to be issued.
6. The system should allow books to be returned.
7. The system should allow books to be searched.
8. The system should generate a library report.
9. The system should store book and member data.
10. The system should validate user input.

## Non-Functional Requirements

### Usability
The system should have a simple menu so that users can easily
understand and operate it.

### Reliability
The system should handle invalid input and prevent duplicate
book and member IDs.

### Maintainability
The program is divided into separate Python modules so that
individual features can be modified easily.

### Error Handling
The system should display suitable messages when a book or
member is not found or when invalid input is entered.

## Expected Outcome

The final system should provide a simple and organized way to
manage basic library activities using Python.
