# Library Management System

## Introduction

The Library Management System is a simple Python-based application
developed to manage books and library members.

The system allows the user to add and view books, register members,
issue and return books, search for books, and generate a library report.

## Objectives

- To manage library books easily.
- To maintain member details.
- To issue and return books.
- To search for books.
- To generate a simple library report.
- To store data so that it can be used again when the program is opened.

## Main Features

1. Book Management
2. Member Management
3. Book Issue and Return
4. Book Search
5. Library Report
6. Data Storage
7. Input Validation

## Technologies Used

- Python
- JSON
- VS Code
- Git and GitHub
